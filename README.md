# Ishani Handa · DaMENSCH portfolio

A walk-through portfolio for DaMENSCH's **Founder's Office – Growth & Marketing** role, in the same style as the boAt and Cars24 portfolios.

- Opens with "Hi DaMENSCH, I'm Ishani." Then Ishani walks a road past school, Christ University, PhonePe and Masters' Union to a DaMENSCH store, following the chapter being read.
- Chapter 05 matches the JD's five KRAs to proof, names what I'd ramp up on, and adds ideas for week one and a 90-day plan.
- A small launch game (*Your move, launch lead*), about, and contact.
- Plain `index.html`, `style.css` and `app.js`; edit them directly.
- The résumé is `assets/Ishani-Handa-CV.pdf` (currently the Pocket FM version). To update it, replace that file.
- `python3 build/make_artifact.py OUT.html` bundles the page into one file for a claude.ai preview.
- Publish with GitHub Pages (Settings → Pages → deploy from branch).
