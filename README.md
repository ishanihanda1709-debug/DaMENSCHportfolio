# Ishani Handa · DaMENSCH portfolio

A portfolio laid out like a D2C clothing store ("DaISHANI"), written for DaMENSCH's **Founder's Office – Growth & Marketing** role.

- Each chapter of the journey is a **collection** and each proof point is a **product**. The JD's five KRAs are "fabrics" (BrandWeave, CreatorKnit, GrowthFlex, NewCut, FounderFit).
- **Made for DaMENSCH** has a size guide that filters products by KRA. **The Ishani Drop** holds the pitch: a creator campaign, a new product idea, three growth tests and a 90-day plan.
- Also: order tracking with Ishani walking the route, quick view, hire bag (checkout opens an email), search, light/dark mode, and the *Build the Drop* game.
- `index.html` is generated: edit the content in `build/make.py`, then run `python3 build/make.py`.
- `style.css` and `app.js` are hand-written.
- The résumé is `assets/Ishani-Handa-CV.pdf` (currently the Pocket FM version). To update it, replace that file.
- Open `index.html` through any static server, or publish with GitHub Pages (Settings → Pages → deploy from branch).
